## ffmpeg (финальные 2–3 с поверх последнего кадра)

```
ffmpeg -i film.mp4 -i scrim-ink-78-1080x1920.png -i monogram-gold-1080x1920.png -i ftc-plate-1080x1920.png \
  -filter_complex "[0:v][1:v]overlay=0:0:enable='gte(t,T0)'[a];[a][2:v]overlay=0:0:enable='gte(t,T0)'[b];[b][3:v]overlay=0:0:enable='gte(t,T0)',format=yuv420p" \
  -c:a copy -movflags +faststart out.mp4
```
`T0` — начало финала. Кадр 720×1280 сначала масштабировать до 1080×1920 (`scale=1080:1920`), накладки рассчитаны на 1080×1920.
